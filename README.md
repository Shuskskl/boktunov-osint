# 🕵️ Boktunov-OSINT (архив)

Многофункциональный OSINT-инструмент (учебный проект, 2025 г.)

## Что было реализовано
- Проверка email через Have I Been Pwned API
- Поиск username на GitHub и Reddit
- Проверка паролей через Pwned Passwords (k-anonymity)
- Демо-анализ номера телефона

## Технологии
- **Фронтенд:** HTML5, CSS3 (Glassmorphism), JavaScript
- **Бэкенд:** Node.js, Express, Axios
- **Безопасность:** Helmet, rate limiting, k-anonymity

## Статус
Проект завершён как учебный. Код доступен для изучения. Локально запускается командой `npm start` после `npm install`.
